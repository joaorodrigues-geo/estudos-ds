# Stock and Revenue Analysis: Tesla & GameStop

This project analyzes the historical stock prices and company revenues of Tesla (TSLA) and GameStop (GME).

## Overview

The dataset comprises:
- Historical stock data collected through the yfinance API.
- Financial revenue data extracted via web scraping using requests and BeautifulSoup.

The main objectives are to:
- Extract, clean, and format financial data.
- Visualize stock prices and revenue trends over time using interactive Plotly charts.
- Demonstrate reproducible data analysis using Python in Jupyter Notebooks.
